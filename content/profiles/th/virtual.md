**Virtuals Protocol** คือแพลตฟอร์มที่ใครก็สร้าง AI agent ได้ ไม่ว่าจะเป็นตัวละครแชตบอต บอตเทรด หรือผู้ช่วยวิจัยตลาด แล้วเปิดตัวโทเคนของ agent นั้นให้คนซื้อขาย โทเคนของ agent ทุกตัวซื้อขายคู่กับ VIRTUAL ซึ่งเป็นโทเคนของแพลตฟอร์มเอง กิจกรรมรอบ ๆ agent จึงสร้างความต้องการให้ VIRTUAL กิจกรรมส่วนใหญ่เกิดบนเครือข่าย Base ของ Coinbase มูลค่ารวมของ VIRTUAL อยู่ที่ {{mcap:virtual}} (อันดับ {{rank:virtual}} ในบรรดาคริปโท)

> **ประเด็นสำคัญ**
> - VIRTUAL จะมีไม่เกิน 1,000 ล้านโทเคน
> - ราว 95% ของค่าธรรมเนียมทั้งหมดที่แพลตฟอร์มเคยเก็บได้ หรือประมาณ 74 ล้านดอลลาร์ ณ ตุลาคม 2026 มาจาก Base
> - ราคาสูงสุดตลอดกาลคือ {{ath:virtual}} ({{athd:virtual}}) วันนี้ราคาอยู่ห่างจากจุดนั้น {{fromath:virtual}}
> - ในเดือนกุมภาพันธ์ 2026 แพลตฟอร์มเปิดตัว "Revenue Network" และสัญญาว่าจะจ่ายสูงสุด 1 ล้านดอลลาร์ต่อเดือนให้ agent ที่ขายบริการให้กันเอง

## ทำงานอย่างไร

ผู้สร้างกำหนดบุคลิกและทักษะให้ agent แล้วเปิดตัวโทเคนของมันบน Virtuals โทเคนใหม่จะจับคู่กับ VIRTUAL และทุกการซื้อขายจะเสียค่าธรรมเนียมเล็กน้อยที่แบ่งกันระหว่างโปรโตคอลกับผู้สร้างและคลังของ agent agent ชื่อดังอย่าง Luna ตัวละครป๊อปสตาร์เสมือน และ AIXBT บัญชีที่โพสต์บทวิเคราะห์ตลาดคริปโท ช่วยทำให้แพลตฟอร์มเป็นที่รู้จัก Agent Commerce Protocol (ACP) ช่วยให้ agent หากันเจอ ตกลงงานกัน และจ่ายเงินกัน โดยเงินจะถูกพักไว้ในบัญชี escrow จนกว่างานจะส่งมอบ

## VIRTUAL ใช้ทำอะไร

VIRTUAL เป็นสกุลเงินหลักของทั้งระบบ คุณต้องใช้มันเพื่อซื้อโทเคน agent บนแพลตฟอร์ม ใช้โหวตด้านการกำกับดูแลและ stake และเป็นสินทรัพย์สำรองในผลิตภัณฑ์ใหม่ ๆ ของ Virtuals ราคาของโทเคนจึงขึ้นลงตามความสนใจใน AI agent บนเชนเป็นหลัก เนื่องจากรายได้ค่าธรรมเนียมส่วนใหญ่มาจากการซื้อขายโทเคน agent ทีมงานจึงกล่าวในเดือนกุมภาพันธ์ 2026 ว่ารายได้ที่ผูกกับการเทรดนั้น "เป็นวัฏจักรและเปราะบาง" และต้องการให้ agent มีรายได้จากบริการแบบเสียเงินมากขึ้น

## เส้นทางที่ผ่านมา

ทีมที่อยู่เบื้องหลัง Virtuals เริ่มต้นในปี 2021 ในชื่อ PathDAO ซึ่งเป็นกิลด์เกมบล็อกเชน ก่อนหันมาทำตัวละคร AI สำหรับเกมและแอป แพลตฟอร์มเปิดตัว agent บน Base เติบโตแรงในช่วงปลายปี 2024 ท่ามกลางกระแสตื่นตัวเรื่อง AI agent ในวงการคริปโท และ VIRTUAL ทำสถิติสูงสุดในต้นเดือนมกราคม 2025 เมื่อกระแส AI agent ซาลงตลอดปี 2025 ราคาก็ร่วงกลับลงมาเกือบทั้งหมด นับจากนั้นแพลตฟอร์มได้เพิ่มเครือข่ายอื่น ๆ รวมถึง Solana เครือข่ายรายได้สำหรับการค้าระหว่าง agent (12 กุมภาพันธ์ 2026) แพลตฟอร์มเปิดตัว Occupy (กันยายน 2026) และแอป Butler สำหรับเทรดอัตโนมัติ

## ทางเลือกอื่น

Virtuals แข่งในธีม "คริปโท AI" กับแพลตฟอร์มที่ใช้สร้างหรือซื้อขาย agent เช่น ระบบนิเวศ ElizaOS และกับเครือข่าย AI อย่าง [Bittensor]({lang}/tao/) และ [Artificial Superintelligence Alliance]({lang}/fet/) ที่เน้นการประมวลผล AI มากกว่าโทเคน agent บน Solana แพลตฟอร์มเปิดตัว memecoin อย่าง pump.fun ก็แย่งเทรดเดอร์กลุ่มเดียวกัน

## ความเสี่ยงหลัก

- **วัฏจักรกระแส:** ความต้องการโทเคน agent ขึ้นอยู่กับเทรนด์ที่อาจจางหายได้เร็ว อย่างที่เกิดขึ้นในปี 2025
- **คุณภาพรายได้:** กิจกรรมส่วนใหญ่มาจากการเทรดโทเคนและสิ่งจูงใจ ทีมงานเองก็บอกว่าการทำกำไรล่าช้าออกไป
- **โทเคน agent:** โทเคน agent ส่วนใหญ่มีขนาดเล็กมากและเสี่ยงสูง หลายตัวสูญเสียมูลค่าเกือบทั้งหมด
- **เทคโนโลยีและบริดจ์:** สมาร์ตคอนแทรกต์และบริดจ์ข้ามเชนอาจถูกแฮ็ก
- **กฎระเบียบ:** กฎเกี่ยวกับ AI และโทเคนที่ผูกกับผลิตภัณฑ์หรือบุคคลยังอยู่ระหว่างการร่าง

## ความหมายสำหรับผู้ที่ซื้อสม่ำเสมอ

VIRTUAL เป็นโทเคนใหม่ที่ผูกกับธีมที่กำลังเป็นกระแสเพียงธีมเดียว และประวัติราคาจนถึงตอนนี้มีแค่ช่วงพุ่งแรงครั้งใหญ่หนึ่งครั้งกับช่วงขาลงยาว การซื้อสม่ำเสมอช่วยกระจายจังหวะเข้าซื้อตามเวลา แต่ถ้าความสนใจใน AI agent ยังต่ำ ก็ไม่อาจป้องกันการขาดทุนได้ หลายคนจึงถือโทเคนแบบนี้เพียงส่วนน้อยของพอร์ตคริปโท ผลตอบแทนในอดีตไม่ได้รับประกันผลตอบแทนในอนาคต
