Ang **Starknet** ay isang "layer 2" na network na nakapatong sa [Ethereum]({lang}/eth/): pinagsasama-sama nito ang libu-libong transaksyon, pinapatunayan gamit ang cryptography na tama ang lahat ng ito, at ipinapadala ang patunay na iyon sa Ethereum — kaya ang paggamit ng mga app dito ay maliit na bahagi lang ng gastos kumpara sa mismong Ethereum. Ginawa ito ng Israeli na kumpanyang StarkWare at naging live noong Nobyembre 2021. Ang kabuuang halaga ng token nitong STRK ay {{mcap:strk}} ({{rank:strk}} sa mga cryptocurrency).

## Paano ito gumagana

Ang Starknet ay isang "ZK rollup". Pinapatakbo ang mga transaksyon sa Starknet, at pagkatapos ay gumagawa ang isang prover ng STARK — isang maikling mathematical na patunay na tama ang pagkakakalkula sa bawat hakbang. Ang kailangan lang gawin ng Ethereum ay suriin ang patunay, hindi ulitin ang buong trabaho, kaya maraming transaksyon ang naghahati sa iisang murang pagsusuri habang umaasa pa rin sa seguridad ng Ethereum. Ang co-founder ng StarkWare na si Eli Ben-Sasson ay isa sa mga siyentipikong nakaimbento ng STARK proofs; ayon sa proyekto, matibay din ang mga ito laban sa mga quantum computer sa hinaharap. Isinusulat ng mga developer ang mga app sa Starknet gamit ang Cairo, isang wikang dinisenyo para madaling mapatunayan ang mga programa.

## Para saan ginagamit ang STRK

Pambayad ang STRK sa transaction fee sa Starknet, ginagamit sa pagboto sa mga upgrade ng network, at ini-stake: ikinakandado ito ng mga may hawak kasama ng mga validator para tumulong na protektahan ang network at kumita ng bagong STRK bilang gantimpala. Nagsimula ang staking noong Nobyembre 2024. Noong Agosto 2025, isang on-chain na botohan (SNIP-31, mga 93.6% ang pabor) ang nagpahintulot na i-stake ang wrapped bitcoin — WBTC, tBTC, LBTC at SolvBTC — kasabay ng STRK, at naging live ang bitcoin staking noong 30 Setyembre 2025. Noong Pebrero 2026, inanunsyo ng Starknet ang strkBTC, isang token na sinusuportahan ng bitcoin na may pribadong balanse at kumpidensyal na paglilipat.

## Ang kuwento nito hanggang ngayon

Itinatag ang StarkWare noong 2018 at una nitong ibinenta ang teknolohiya bilang StarkEx, isang engine na ginamit ng mga exchange gaya ng dYdX at Immutable. Binuksan ang pangkalahatang network na Starknet noong Nobyembre 2021. Inilunsad ang STRK token noong 20 Pebrero 2024 kasama ang malaking airdrop sa mga user at developer; pinakamataas ang presyo nito sa mga unang araw, saka bumaba sa halos buong sumunod na dalawang taon habang unti-unting na-unlock ang malalaking bilang ng token na hawak ng mga naunang investor at ng team. Noong 2025–2026, muling iniposisyon ng proyekto ang Starknet bilang lugar para gamitin ang bitcoin, hindi lang ang Ethereum.

## Mga alternatibo

Kakumpitensya ng Starknet ang iba pang layer 2 network ng Ethereum: [Arbitrum]({lang}/arb/) at [Optimism]({lang}/op/) (optimistic rollup), ang Base ng Coinbase, at iba pang ZK rollup gaya ng [ZKsync]({lang}/zk/), Scroll at Linea. Ang natatangi rito ay ang STARK proofs at ang wikang Cairo; ang downside, kailangang mag-aral ng bagong wika ang mga developer ng Ethereum.

## Pangunahing panganib

- **Kompetisyon:** maraming layer 2 network ang nag-aagawan sa parehong mga user at app, at ang pinakaginagamit ang nakakakuha ng karamihan sa aktibidad.
- **Supply ng token:** nagdadagdag ng bagong STRK ang staking, at na-unlock sa loob ng ilang taon ang mga token ng mga naunang investor at contributor.
- **Teknolohiya:** maaaring pumalya o ma-hack ang komplikadong cryptography, mga bridge at ang mga nag-iisyu ng wrapped bitcoin; ilang bahagi ng network ay pinapatakbo pa rin ng maliit na grupo ng mga operator.
- **Pagkuha ng halaga:** maganda sa mga user ang murang fee, pero mas kaunti ang natitirang kita na puwedeng sumuporta sa presyo ng token.
- **Malalaking galaw:** gaya ng karamihan sa mga batang token, nawala na noon sa STRK ang karamihan ng halaga nito mula sa rurok.

## Ano ang ibig sabihin nito kung regular kang bumibili

Bata at pabagu-bagong token ang STRK na maikli pa ang kasaysayan ng presyo, kaya ang regular na pagbili rito ay halos puro pababang presyo ang naranasan sa ngayon. Ang pagbili ng parehong halaga nang regular ay nagkakalat ng panganib ng maling timing ng pagpasok, pero hindi ito proteksyon laban sa mahabang pagbaba. Maraming tao ang naglalaan lang ng maliit na bahagi ng kanilang crypto para sa ganitong token. Hindi garantiya ang mga nakaraang resulta ng kita sa hinaharap.
