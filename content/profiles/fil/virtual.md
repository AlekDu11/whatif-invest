Ang **Virtuals Protocol** ay isang platform kung saan kahit sino ay puwedeng gumawa ng AI agent — isang chatbot na karakter, trading bot o assistant sa market research — at maglunsad ng token para rito na mabibili at maibebenta ng mga tao. Bawat agent token ay tine-trade laban sa VIRTUAL, ang sariling token ng platform, kaya ang aktibidad sa paligid ng mga agent ay lumilikha ng demand para rito. ## Paano ito gumagana

Binibigyan ng creator ang agent ng personalidad at mga kakayahan, saka inilulunsad ang token nito sa Virtuals. Ipinapares ang bagong token sa VIRTUAL, at bawat trade ay may maliit na fee na hinahati sa pagitan ng protocol at ng creator at treasury ng agent. Nakatulong ang mga kilalang agent gaya ni Luna, isang virtual na pop-star na karakter, at ng AIXBT, isang account na nagpo-post ng pagsusuri sa crypto market, para sumikat ang platform. Pinapayagan ng Agent Commerce Protocol (ACP) ang mga agent na hanapin ang isa't isa, magkasundo sa isang gawain at magbayad para rito, habang nakatago ang pera sa escrow hanggang maihatid ang trabaho.

## Para saan ginagamit ang VIRTUAL

Ang VIRTUAL ang pangunahing pera ng buong sistema: kailangan mo ito para bumili ng agent token sa platform, ginagamit ito sa mga governance vote at staking, at ito ang reserve asset sa mga mas bagong produkto ng Virtuals. Kaya pangunahing tumataas at bumababa ang token kasabay ng interes sa mga on-chain AI agent. Dahil karamihan ng kita mula sa fee ay galing sa trading ng agent token, sinabi ng team noong Pebrero 2026 na ang kitang nakatali sa trading ay "cyclical at marupok" at gusto nitong mas kumita ang mga agent mula sa bayad na serbisyo.

## Ang kuwento nito hanggang ngayon

Nagsimula ang team sa likod ng Virtuals noong 2021 bilang PathDAO, isang blockchain gaming guild, at kalaunan ay lumipat sa mga AI character para sa mga laro at app. Sumikat ang agent launchpad sa Base noong huling bahagi ng 2024, sa gitna ng alon ng kasabikan sa mga AI agent sa crypto, at naitala ng VIRTUAL ang record nito sa simula ng Enero 2025. Nang humupa ang hype sa AI agent noong 2025, bumagsak ang presyo nang halos pabalik sa pinanggalingan. Mula noon, nagdagdag ang platform ng iba pang network, kabilang ang Solana, isang revenue network para sa agent-to-agent commerce (12 Pebrero 2026), ang Occupy launchpad (Setyembre 2026) at ang Butler app para sa automated trading.

## Pangunahing panganib

- **Mga hype cycle:** nakasalalay ang demand sa agent token sa isang trend na puwedeng mabilis na maglaho, gaya ng nangyari noong 2025.
- **Kalidad ng kita:** karamihan ng aktibidad ay galing sa trading ng token at mga insentibo; inamin mismo ng team na naantala ang pagiging kumikita.
- **Mga agent token:** karamihan sa mga agent token ay napakaliit at napakapanganib; marami ang nawalan ng halos lahat ng halaga.
