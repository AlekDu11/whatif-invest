Wie verbindet man Binance Wallet mit einer DEX? Öffnen Sie die offizielle Website der DEX, klicken Sie auf Connect Wallet (Wallet verbinden), wählen Sie Binance Wallet (oder WalletConnect und scannen Sie den QR-Code mit der Binance-App) und bestätigen Sie in der App. Um Coins zurückzuschicken, kopieren Sie Ihre Binance-Einzahlungsadresse für denselben Coin und dasselbe Netzwerk und senden Sie aus der Wallet dorthin – zuerst einen kleinen Testbetrag.

Das Wichtigste

  • Eine DEX (dezentrale Börse – eine Website, auf der Sie Token direkt aus Ihrer eigenen Wallet tauschen) braucht nie Ihr Wiederherstellungspasswort oder Ihre Seed-Phrase. Die Verbindung erlaubt der Seite nur, Sie um eine Signatur zu bitten; nichts bewegt sich, bevor Sie bestätigen.
  • Das Netzwerk muss auf beiden Seiten gleich sein (BNB Smart Chain zu BNB Smart Chain, Solana zu Solana). Ein falsches Netzwerk oder eine falsche Adresse kann den Verlust der Coins bedeuten.
  • Jedes „Approve“ erlaubt einer Seite, einen Token für Sie auszugeben. Geben Sie kleine Freigaben und entfernen Sie die, die Sie nicht mehr nutzen.

Diese Lektion setzt Binance Wallet erstellen fort. Memecoins sind extrem riskant – nutzen Sie nur Geld, dessen Verlust Sie verkraften können.

Schritt 1. Die echte Website öffnen

Gefälschte DEX-Seiten mit demselben Logo gehören zu den häufigsten Fallen.

  1. Tippen Sie die Adresse selbst ein oder nutzen Sie ein Lesezeichen. Klicken Sie keine Anzeigen in Suchergebnissen und keine Links aus Chats.
  2. Prüfen Sie die Adresszeile Buchstabe für Buchstabe.
  3. Prüfen Sie, ob die DEX in dem Netzwerk arbeitet, in dem Ihre Coins liegen.

Schritt 2. Wallet verbinden

Je nach Gerät gibt es drei Wege:

  • Am Computer mit der Browser-Erweiterung Binance Wallet (Chrome oder Brave). Melden Sie sich in der Erweiterung an, indem Sie ihren QR-Code mit der Binance-App scannen. Klicken Sie dann auf der DEX auf Connect oder Connect Wallet, wählen Sie Binance Wallet und bestätigen Sie das Fenster.
  • Am Computer ohne Erweiterung. Klicken Sie auf der DEX auf Connect Wallet → WalletConnect. Ein QR-Code erscheint. Scannen Sie ihn mit dem Scanner in der Binance-App und tippen Sie auf Connect.
  • Am Handy. Öffnen Sie die DEX im Handy-Browser, tippen Sie auf Connect Wallet, wählen Sie Binance Wallet aus der Liste und bestätigen Sie in der App.

Lesen Sie das Fenster vor dem Bestätigen: Name der Seite, Adresse und Netzwerk. Wirkt etwas falsch, tippen Sie auf Cancel (abbrechen).

Schritt 3. Tauschen und jede Signatur lesen

  1. Wählen Sie den Coin, mit dem Sie zahlen, und den gewünschten Token (suchen Sie den Token per Kontraktadresse, nicht per Namen).
  2. Geben Sie einen kleinen Betrag ein und prüfen Sie Kurs, Slippage (die größte Preisänderung, die Sie akzeptieren) und Netzwerkgebühr.
  3. Wenn Sie einen Token zum ersten Mal verkaufen, verlangt die Seite Approve (Erlaubnis, diesen Token auszugeben). Wenn die App es zulässt, setzen Sie einen Betrag statt „unlimited“ (unbegrenzt).
  4. Bestätigen Sie den Tausch in der App. Ist eine Signaturanfrage eine Seite voller unlesbarem Code oder ergibt keinen Sinn – nicht signieren.

Schritt 4. Coins zurück aufs Binance-Konto schicken

  1. Wechseln Sie in der Binance-App zu Exchange → Assets → Deposit (Börse → Vermögen → Einzahlung). Wählen Sie den Coin (zum Beispiel BNB).
  2. Wählen Sie das Netzwerk (zum Beispiel BNB Smart Chain). Kopieren Sie die Einzahlungsadresse. Manche Coins brauchen zusätzlich ein Memo/Tag – kopieren Sie es ebenfalls.
  3. Wechseln Sie zu Wallet → Send (senden). Wählen Sie denselben Coin und dasselbe Netzwerk. Fügen Sie die Adresse ein (und das Memo, falls vorhanden).
  4. Senden Sie zuerst einen kleinen Testbetrag. Ist er auf dem Binance-Konto angekommen, senden Sie den Rest.

Lassen Sie etwas BNB oder SOL in der Wallet: Jede Aktion auf der Blockchain, selbst eine fehlgeschlagene, kostet eine Netzwerkgebühr. Manche Memecoins lassen sich gar nicht auf die Börse einzahlen (sie listet sie nicht) – um auszuzahlen, tauschen Sie sie vorher in der Wallet in BNB, SOL oder USDT.

Schritt 5. Trennen und aufräumen

  1. Wenn Sie fertig sind, trennen Sie die Seite (in den Einstellungen für verbundene Seiten bzw. WalletConnect in der Wallet oder mit dem Button Disconnect auf der DEX).
  2. Prüfen Sie ab und zu Ihre Token-Freigaben und widerrufen Sie die, die Sie nicht brauchen. Ein Widerruf kostet eine kleine Gebühr.
  3. Melden Sie sich an fremden Computern von der Erweiterung ab.

Verfolgen Sie gekaufte Token in Ihrem Portfolio und sehen Sie Live-Daten zu Memecoins auf unserer Memecoin-Seite.

⚠️ Vorsicht

  • Eine Seite oder ein „Support“ will Ihr Wiederherstellungspasswort, Ihre Seed-Phrase oder eine „Wallet-Synchronisierung“. Keine echte DEX und kein Binance-Mitarbeiter tut das. Schließen Sie die Seite.
  • Unbegrenzte Freigaben und blindes Signieren. Eine bösartige Freigabe oder Signatur kann einem Betrüger erlauben, diesen Token später ohne weitere Bestätigung abzuziehen.
  • Falsches Netzwerk, vergessenes Memo oder eine eingefügte Adresse, die sich verändert hat. Schadsoftware kann kopierte Adressen austauschen. Vergleichen Sie jedes Mal die ersten und letzten Zeichen und testen Sie mit kleinem Betrag.
