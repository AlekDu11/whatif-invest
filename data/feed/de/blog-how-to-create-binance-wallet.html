Wie erstellt man eine Binance Wallet? Öffnen Sie die Binance-App, wechseln Sie oben zum Tab Wallet, tippen Sie auf Create Keyless Wallet (Wallet ohne Schlüssel erstellen) und sichern Sie sie mit einem Wiederherstellungspasswort. Das dauert ein paar Minuten, braucht keine Seed-Phrase und gibt Ihnen eine Self-Custody-Wallet (eine Wallet, in der Sie und nicht die Börse die Coins kontrollieren) zum Kauf von On-Chain-Token wie Memecoins.

Das Wichtigste

  • Binance Wallet steckt in der Binance-App. Sie brauchen ein verifiziertes Binance-Konto, aber die Coins in der Wallet sind Self-Custody – für die Sicherung sind Sie selbst verantwortlich.
  • Es ist eine „schlüssellose“ (MPC-)Wallet: Der Schlüssel ist in 3 Teile geteilt – auf Ihrem Handy, in Ihrem Cloud-Backup und bei Binance. Je 2 davon öffnen die Wallet.
  • Lassen Sie das Backup nie weg. Wenn Sie Ihr Handy verlieren und das Wiederherstellungspasswort vergessen, kann Binance die Wallet nicht wiederherstellen.

Bevor Sie anfangen: Die meisten neuen Memecoins verlieren fast ihren ganzen Wert. Nutzen Sie nur Geld, dessen kompletten Verlust Sie verkraften – siehe was Memecoins sind.

Was Sie brauchen

  • Ein Handy mit der offiziellen Binance-App (laden Sie sie nur aus dem App Store, von Google Play oder von binance.com – gefälschte Apps sind verbreitet).
  • Ein Binance-Konto mit abgeschlossener Identitätsprüfung (KYC – Ausweis zeigen). Falls Sie noch keins haben, können Sie sich über unseren Link anmelden: Binance Wallet.
  • Etwas BNB oder SOL auf Ihrem Binance-Konto zum Kaufen und für Netzwerkgebühren.

Schritt 1. Wallet öffnen

  1. Melden Sie sich in der Binance-App an.
  2. Wechseln Sie oben auf dem Bildschirm von Exchange (Börse) zu Wallet.
  3. Tippen Sie auf Create Keyless Wallet. (Haben Sie schon eine andere Wallet, gibt es noch Import Wallet (Wallet importieren) – Einsteiger brauchen das nicht.)

Das Erstellen dauert Sekunden. Die App zeigt Ihnen keine 12 oder 24 Seed-Wörter: Stattdessen nutzt sie MPC (Multi-Party Computation – der Schlüssel wird in Teile geteilt, die nie an einem Ort liegen).

Schritt 2. Backup anlegen (nicht überspringen)

Die App bietet drei Wege, Ihren Backup-Teil zu speichern. Wählen Sie einen:

  • iCloud oder Google Drive. Sie legen ein Wiederherstellungspasswort fest, das nur Sie kennen. Der Teil wird damit verschlüsselt und in Ihrer Cloud gespeichert.
  • QR-Code. Sie legen ein Wiederherstellungspasswort fest und speichern einen QR-Code; der Teil liegt in einer dezentralen Cloud.
  • Quick Backup (Schnell-Backup). Sie bestätigen per Face ID oder Fingerabdruck; kein Passwort, aber der Teil liegt bei einem Drittanbieter.

Schreiben Sie das Wiederherstellungspasswort auf Papier und bewahren Sie es sicher auf. Prüfen Sie dann: Tippen Sie auf Settings (Einstellungen; oben links auf Home oder Assets) → Wallet Management (Wallet-Verwaltung). Dort sollte die Markierung Backed Up (gesichert) stehen.

Schritt 3. Coins von Binance in die Wallet übertragen

  1. Tippen Sie in der Wallet auf Receive (empfangen) → Withdraw from Binance Exchange (von der Binance-Börse abheben).
  2. Wählen Sie den Coin (zum Beispiel BNB) und das Netzwerk (BNB Smart Chain für BNB, Solana für SOL). Das Netzwerk muss passen.
  3. Geben Sie den Betrag ein. Vor der Bestätigung zeigt die App die Gebühr und den Endbetrag.
  4. Wählen Sie, ob das Geld vom Spot- oder Funding-Konto kommt, tippen Sie auf Withdraw (abheben), prüfen Sie Adresse und Netzwerk und tippen Sie auf Confirm (bestätigen).

Beginnen Sie mit einem kleinen Testbetrag. Eine bestätigte Überweisung lässt sich nicht stornieren. Lassen Sie immer etwas BNB oder SOL in der Wallet: Jede Aktion auf der Blockchain kostet eine Netzwerkgebühr (Gas), auch eine fehlgeschlagene.

Schritt 4. Den richtigen Token per Kontraktadresse finden

Viele Memecoins haben Kopien mit gleichem Namen und Logo. Die einzige verlässliche Kennung ist die Kontraktadresse (eine lange Folge aus Buchstaben und Zahlen, die für jeden Token einzigartig ist).

  1. Holen Sie die Adresse aus einer vertrauenswürdigen Quelle: dem verifizierten Konto des Projekts, einer großen Datenseite oder einer Token-Seite auf unserer Memecoin-Seite.
  2. Fügen Sie die Adresse im Bildschirm Markets (Märkte) oder Trade (Handeln) der Wallet in die Suche ein, statt den Namen zu tippen.
  3. Vergleichen Sie die ersten und letzten 4–6 Zeichen mit Ihrer Quelle.

Schritt 5. Token vor dem Kauf prüfen

Auf unserer Memecoin-Seite zeigt jede Token-Seite den Sicherheitscheck von Binance und die wichtigsten Zahlen. Achten Sie auf:

  • Liquidität – wie viel Geld im Handelspool liegt. Wenig Liquidität = Sie können eventuell nicht verkaufen.
  • Holder und Anteil der Top 10 – halten wenige Wallets den Großteil des Angebots, können sie den Preis abstürzen lassen.
  • Alter – ein Token, der vor einer Stunde erstellt wurde, ist ein Lottoschein.
  • Warnungen – erscheint irgendeine Risiko- oder Sicherheitswarnung, hören Sie auf.

Binance sagt selbst, dass es die Token auf Meme Rush (seinem Feed brandneuer Memecoins) nicht prüft – die Prüfung liegt also bei Ihnen. Unsere Lektion zu Betrug und Rug Pulls listet die Warnsignale auf.

Schritt 6. Tauschen

  1. Öffnen Sie Trade → Swap (Tausch). Wählen Sie, womit Sie zahlen (BNB), und den gewünschten Token im selben Netzwerk.
  2. Geben Sie einen kleinen Betrag ein. Lesen Sie den Kurs, die Slippage (die größte Preisänderung, die Sie akzeptieren, bevor der Trade scheitert) und die Netzwerkgebühr.
  3. Manche Token brauchen vorher einen Approve-Schritt (Freigabe); er kostet eine kleine Gebühr.
  4. Tippen Sie auf Swap und bestätigen Sie mit Ihrem Passkey oder 2FA.

Zum Verkaufen machen Sie dasselbe umgekehrt. Wenn Sie die allerneuesten Token sehen wollen, gibt es im Tab Markets Meme Rush: Brandneue Token werden dort auf einer „Bonding Curve“ gehandelt und können die Wallet erst verlassen, wenn sie auf eine normale DEX (dezentrale Börse) „migrieren“. Das ist die riskanteste Ecke des Marktes.

⚠️ Vorsicht

  • Kein Backup oder ein Passwort in Screenshots. Handy und Passwort weg – die Coins sind für immer verloren.
  • Falsches Netzwerk oder falsche Adresse. Laut Binance-FAQ können an eine falsche Adresse gesendete Token nicht erstattet werden. Senden Sie immer einen Testbetrag.
  • Gefälschte Token und „Support“-Nachrichten. Suchen Sie nur per Kontraktadresse. Binance-Mitarbeiter fragen nie nach Ihrem Wiederherstellungspasswort und bitten Sie nie, Ihre Wallet auf einer Website zu „verifizieren“.
