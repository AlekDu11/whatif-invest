Sumirit ng mga 19% ang shares ng Micron noong Lunes, Nobyembre 23 — isa sa pinakamalalaking pagtaas sa malalaking chip stock — matapos ibalik ng board ng Nvidia si Jensen Huang bilang CEO. Nawalan ang memory maker ng halos sangkapat ng halaga nito sa limang naunang session.

Ano ang nangyari

  • Nakaraang linggo: limang araw na pagbaba ang bumura sa 23.6% ng market value ng Micron, kasama ang halos 14% na bagsak noong Biyernes sa $594.51, ang pinakamababang closing mula Mayo.
  • Lunes, pagbubukas sa 14:30 UTC: nag-gap up ang stock kasabay ng buong tech sector; bandang 15:26 UTC nasa mga $717 (+20.7%), at $718.72 ang high.
  • 16:31 UTC: mga $710, humigit-kumulang +19%, habang tumaas ng 7% ang Nasdaq.

Bakit ito gumalaw

Ang mitsa ay ang Nvidia: gumagawa ang Micron ng high-bandwidth memory (HBM) na katabi ng mga AI processor ng Nvidia, kaya tinamaan din ng pangamba sa pamumuno ng Nvidia ang memory stocks. Pinanatili ng Citi ang Buy rating at sinabing sobra ang bentahan sa memory. Sinabi ng CEO ng Micron noong Nobyembre 18 na mga 75% ng memory supply nito para sa 2027 ay nabenta na. Sa kabilang banda, nagbabala ang TrendForce noong Huwebes na maaaring bumaba nang hanggang 5% ang NAND contract prices sa unang bahagi ng 2027 — isa sa mga dahilan ng bagsak noong nakaraang linggo.
